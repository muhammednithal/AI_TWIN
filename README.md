# 🧬 AI Twin – Chat With Your Digital Clone

An intelligent AI Twin system built using **Go + Gemini AI + React + Tailwind CSS**.  
Your twin learns your personality using **samples, tone sliders, and memory storage**.  
It remembers your facts, preferences, and chats like you.

---

### 🔥 Features

| Feature                 | Description                                                             |
| ----------------------- | ----------------------------------------------------------------------- |
| 🧠 Personality Creation | Create a custom “AI Twin” using text samples + slider-controlled traits |
| 💬 Real-time Chat       | Talk with your twin, which responds in your tone                        |
| 📌 Auto Memory          | System extracts information and stores it automatically                 |
| 📝 Manual Memory        | Add custom memories about yourself (e.g., food likes, birthday)         |
| 🔐 Secure Auth          | JWT authentication system                                               |
| 🎨 Beautiful UI         | Custom-built sleek UI using Tailwind CSS                                |
| 🌗 Light/Dark Theme     | Toggle between themes                                                   |

---

## 🏗️ Tech Stack

### **Backend**

- Go (Gin Framework)
- Gemini API (Generative AI)
- PostgreSQL + GORM
- JWT Authentication
- Embeddings + Vector Search (RAG)

### **Frontend**

- React (Vite)
- Tailwind CSS
- Axios
- LocalStorage Auth
- Smooth UX & Theming
